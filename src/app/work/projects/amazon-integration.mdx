## Overview

Created a robust integration with Amazon Vendor Direct Fulfillment API that automates shipment confirmations with container details and tracking information. The system handles thousands of transactions daily with intelligent retry logic and error recovery.

## Key Achievements

- Processes 10,000+ orders monthly without manual intervention
- Automated container packing and tracking number management
- Reduced shipment confirmation errors by 95%

## Technologies Used

- **Python**
- **Amazon SP-API**
- **FastAPI**
