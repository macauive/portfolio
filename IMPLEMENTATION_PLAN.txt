# Portfolio Website Implementation Plan

## Overview
Build a single-page, minimalist portfolio website using Next.js 14 (App Router), TypeScript, Tailwind CSS, and Framer Motion. Design inspired by Apple OS and cluely.com aesthetic with soft shadows, clean spacing, smooth animations, and perfect mobile responsiveness.

## User Preferences
- **Hero**: Brief intro + immediate project showcase
- **Layout**: Interactive grid with technology/category filters
- **Modals**: Non-technical descriptions, tech badges, key achievements (client-friendly)
- **Tech Stack**: TypeScript, Next.js, Tailwind CSS, Framer Motion

## Animation Strategy

**Framer Motion Usage:**
- Hero: Fade in + slide up (0.6s)
- Project cards: Staggered fade in (0.05s delay per card)
- Modal backdrop: Fade in (0.2s)
- Modal content: Scale + fade with spring physics
- Hover: Shadow/color transitions (0.3s)

**Performance:**
- Use transform and opacity only
- Avoid animating layout properties
- GPU-accelerated animations
